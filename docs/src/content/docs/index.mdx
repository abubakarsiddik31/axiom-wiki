## What is Axiom Wiki?

Unlike RAG systems that re-derive answers from raw sources on every query, Axiom **compiles** knowledge into an interconnected wiki of markdown pages and keeps it current as new sources arrive.

<CardGrid stagger>
  <Card title="Drop files, get a wiki" icon="document">
    Drop PDFs, markdown, images, spreadsheets (CSV/TSV), or URLs into your `raw/` folder. Axiom reads them, extracts entities and concepts, and creates cross-linked wiki pages automatically.
  </Card>
  <Card title="Auto-wiki your codebase" icon="seti:folder">
    Run `axiom-wiki autowiki` inside any project to generate structured documentation — architecture, modules, tech stack — with one command.
  </Card>
  <Card title="Stay in sync" icon="refresh">
    As your codebase evolves, `axiom-wiki sync` detects changes and updates only the affected wiki pages. No manual maintenance.
  </Card>
  <Card title="Hybrid Semantic Search" icon="magnifier">
    Search that actually understands. Combines traditional keywords with vector embeddings for conceptual retrieval. Supports Google, OpenAI, and Ollama.
  </Card>
  <Card title="Live Maintenance" icon="rocket">
    The wiki updates itself when your code changes. Tier 1 (deterministic) handles renames; Tier 2 (agent-based) rewrites pages to reflect new logic.
  </Card>
  <Card title="Forensic Citation Proofs" icon="approve-check">
    Zero hallucinated citations. Mechanically audit paragraph citations against raw files — timestamps (`[mm:ss]`), pages (`[p. N]`), and quotes. Run `axiom-wiki lint --forensic` in CI or git pre-commit hooks.
  </Card>
  <Card title="Strict Grounded Querying" icon="open-book">
    Query your wiki with zero extrapolation. In strict forensic mode (`axiom-wiki query --forensic`), the model is strictly barred from pre-trained knowledge and only speaks from verified docs.
  </Card>
  <Card title="Browse it like a real wiki" icon="window">
    `axiom-wiki serve` opens a local read-only web UI with a dashboard, hybrid search, a link graph, and "what links here" backlinks on every page.
  </Card>
  <Card title="Works everywhere" icon="laptop">
    Nine providers from Google Gemini's free tier to Grok, plus fully offline with Ollama. Your data stays local. Plain markdown files work with Obsidian, VS Code, or any editor.
  </Card>
</CardGrid>
